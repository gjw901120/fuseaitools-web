            <h3 style="color:#f3f4f6;">Workshop: A Complete Development Loop</h3>
            <p style="color:#d1d5db;">Traditional workflow: write code, switch to browser to test, manually diff, submit PR, wait for CI, find issues, fix, resubmit.</p>

            <p style="color:#d1d5db;">Claude Code workflow:</p>
            <p style="color:#fb7185;font-style:italic;">"Implement this feature, then run it in the desktop preview. Once the preview passes, review the code and open a PR. Monitor CI — if anything fails, auto-fix it. Merge once all checks pass."</p>

            <p style="color:#d1d5db;">Claude Code starts the dev server, previews the app in the desktop interface, reads console logs, captures errors, and iterates. You can select visual elements directly in the preview and pass feedback to Claude.</p>

            <p style="color:#d1d5db;">During review, Claude inspects the local diff and leaves comments in the desktop diff view — highlighting bugs, suggesting improvements, and flagging potential issues. For GitHub code, Claude Code tracks PR status including CI check passes and failures, using the underlying GitHub CLI. You can enable auto-fix to let Claude automatically attempt to fix detected CI failures; with auto-merge enabled, Claude merges the PR once all checks pass.</p>

        <section class="session-migration">
            <h2 style="color:#f9fafb;border-bottom-color:#374151;">Scenario 2: Session Migration Replaces Repeated Setup</h2>
            <p style="color:#d1d5db;">Claude Code sessions can now migrate across devices. Start a session in the CLI, run <code style="background:#1f2937;padding:2px 6px;border-radius:4px;">/desktop</code> to bring the full session context into the desktop app. You can also move a local desktop session to the cloud using the "Continue with Claude Code on the web" button, then continue from the web or Claude mobile app.</p>

            <h3 style="color:#f3f4f6;">Technique: Tasks Run in the Background, You Move On</h3>
            <p style="color:#d1d5db;">You can work on one task in a Claude Code session, open a PR, then switch to a new task. In the background, Claude Code monitors the original task's PR, attempts to fix CI failures — so when you switch back, the PR is ready to merge (or already auto-merged).</p>

            <p style="color:#d1d5db;">This means you don't need to "watch" a task until it's done. Start, delegate, switch away, come back to collect results — that's the correct usage pattern for an agentic workflow.</p>
        </section>

            <h3 style="color:#f3f4f6;">Subscription vs. API: Choosing the Right Path</h3>
            <p style="color:#d1d5db;">According to Anthropic's operational data, in enterprise deployments each developer spends approximately $13/day on average, $150–250/month, with 90% of users below $30/day. Based on Sonnet 5 rates, if your daily output exceeds 200K tokens, the Max 5x subscription ($100/month) may be more economical than API. A common pattern: use subscription for interactive work, API Key for CI and batch tasks (eligible for Batch 50% discount).</p>

                <li style="margin-bottom:6px;"><strong style="color:#f43f5e;">Engineering teams:</strong> Claude Code</li>

            <p style="color:#d1d5db;">For deployment controls, employees sign in with existing work accounts (IAM Identity Center, Microsoft Entra ID, Okta, etc.) — no shared secrets, no cloud credentials on end-user machines. Policy templates can be exported from the settings UI and pushed via Intune, GPO, or Jamf. Offline installers cover air-gapped environments.</p>

            <h3 style="color:#f3f4f6;">Xcode Integration</h3>

Developers can use Claude's coding capabilities directly within Xcode: code assistance with natural language interaction, automatic project context fetching, debugging, refactoring, and building new features. Coding tools can generate documentation, explain selected code, create SwiftUI previews and Playgrounds, and make code changes directly in the editor.</p>
