            <h2 style="color:#f9fafb;border-bottom-color:#374151;">V. Prompt Techniques and Examples</h2>

            <h3 style="color:#f3f4f6;">1. Six Core Techniques</h3>
            <p style="color:#d1d5db;"><strong style="color:#818cf8;">Technique 1 — "Bake the details" in image-to-video.</strong> Details must be baked into the reference image. If the skin in a static reference looks like wax or plastic, no prompt can fix it at generation time. Professionals spend 90% of their time perfecting the static reference.</p>
            <p style="color:#d1d5db;"><strong style="color:#818cf8;">Technique 2 — Adopt the "reduction prompt" mindset.</strong> Avoid over-specifying details in motion prompts. Since details are already in the reference image, motion prompts need only describe movement and mood. Over-detailed cues such as "pores" or "wrinkles" introduce visual noise.</p>
            <p style="color:#d1d5db;"><strong style="color:#818cf8;">Technique 3 — Follow the "4-6 second rule."</strong> Hailuo AI's professional "sweet spot" per generation is 4-6 seconds. Beyond that threshold, the probability of artifacts such as limb merging or background warping rises sharply. For longer content, generate several 4-6 second clips and stitch them in post-production.</p>
            <p style="color:#d1d5db;"><strong style="color:#818cf8;">Technique 4 — The single-axis motion rule.</strong> Constrain camera motion to one dominant direction to maximize pixel-interpolation stability. Multi-axis moves (e.g., "move left while zooming and tilting down") often distort the subject.</p>
            <p style="color:#d1d5db;"><strong style="color:#818cf8;">Technique 5 — Use a structured prompt formula.</strong> Organize prompts with the modular structure [subject/action] + [environment] + [camera movement/shot] + [lighting/atmosphere] so the AI understands information hierarchy.</p>
            <p style="color:#d1d5db;"><strong style="color:#818cf8;">Technique 6 — Label multi-shot prompts with a timeline.</strong> For multi-shot narratives, mark each phase with time ranges — e.g., 0-3s establishes the scene, 5-12s introduces the action.</p>

            <h2 style="color:#f9fafb;border-bottom-color:#374151;">VI. Professional Workflow: From Generation to Delivery</h2>

            <h3 style="color:#f3f4f6;">1. The Image-to-Video Workflow</h3>
            <p style="color:#d1d5db;">For professional-grade quality, Hailuo AI's core workflow is <strong>Image-to-Video (I2V)</strong>:</p>
            <ul style="color:#d1d5db;">
                <li style="margin-bottom:6px;">Generate a <strong>Master Reference Image</strong> with a high-quality image tool, ensuring details are baked in.</li>
                <li style="margin-bottom:6px;">Upload it as the anchor: feed this image to Hailuo AI as the input reference.</li>
                <li style="margin-bottom:6px;">Inject a motion prompt: describe only the desired motion and mood change.</li>
            </ul>

            <h3 style="color:#f3f4f6;">2. The 4-6 Second Clip Strategy</h3>
            <p style="color:#d1d5db;">Professional creators treat AI as a source of "raw footage," not a final-output generator. The best practice is to generate multiple 4-6 second clips, then stitch them in post tools such as DaVinci Resolve or Premiere Pro for longer narratives.</p>

            <h3 style="color:#f3f4f6;">3. The Manual Keyframe System</h3>
            <p style="color:#d1d5db;">Because Hailuo AI has no cloud-based "Subject ID" or character-saving system, character consistency is managed through a file-based workflow:</p>
            <ul style="color:#d1d5db;">
                <li style="margin-bottom:6px;">Keep one "Master Reference Image" per project as the visual DNA.</li>
                <li style="margin-bottom:6px;">Use the exact same reference file for every generation.</li>
                <li style="margin-bottom:6px;">Do not use a previously AI-generated frame as a new reference — this causes "generational degradation."</li>
            </ul>

            <h3 style="color:#f3f4f6;">4. The Media Agent Workflow</h3>
            <p style="color:#d1d5db;">For automated multimodal creation, use Media Agent: <strong>one-click mode</strong> (describe what you want and the Agent completes the full flow) or <strong>step-by-step mode</strong> (manually upload image, video, and audio assets and tailor each step).</p>
